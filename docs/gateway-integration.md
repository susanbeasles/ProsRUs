# Implemented shared gateway contract

Control owns the existing canonical issuer `https://control.vespoli.me` and canonical `/mcp` audience. Job Stack uses closed selected-v2 workspace grants with exact current owner/data owner, capability revision, workspace selectors and operation authority. Infrastructure or broad profile sessions do not imply Job Stack authority. Five read operations are enabled: `job_stack_records`, `job_stack_version`, `job_stack_versions`, `job_stack_request` and `job_stack_protection`. Registered mutation/effect operations remain unavailable by default; this guide adds no scope, grant kind or route.

The Control `JOB_STACK` binding selects the private Product service `job-stack-staging`, named entrypoint `JobStack`. The Product default fetch returns 404. The packaged Product's reciprocal `CONTROL_AUTHORITY` binding selects Control's named `JobStackAuthority` entrypoint. Product/Coordinator read and before-ack guards revalidate current authority; supplied profile data or historical imported observations never establish grants, versions, protection or pursuit approval.

Owner presentation requires genuine signed Access identity through the shared checked private contact gate. Job Stack additionally requires an explicitly configured, independently qualified hardware-assurance profile and bounded lease. Existing sessions bind selected grant/revisions, stable proof context and target; deadlines only narrow, expiry/revocation is terminal, and reads/refresh cannot establish or extend a lease. Selected owner operations use same-origin one-use nonces bound to the exact presentation, grant, method and target. The optional exact owner presentation origin serves approved owner GET presentation/data paths and explicit same-origin, one-use-nonce-bound session establish/revoke POSTs. Productive alias POSTs remain unavailable; OAuth/MCP/protocol metadata remain canonical. Product asset requests receive sanitized URL/GET requests without credential or assertion forwarding.

`integration/gateway.mjs` is a retired fail-closed broad-profile adapter: its scope list is empty and both helpers throw. It is preserved source, not current wiring or instructions to add a dedicated broad OAuth resource. The maintained Control adapter/authority/presentation/session modules implement the contract above.
