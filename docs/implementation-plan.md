Run affected unit tests, strict actual consumers, generators, builds and signed synthetic Control/Product/Coordinator/R2/D1 acceptance. Public fixtures are independent and exceed one page. Preserve original private evidence separately. Independently review the complete source/composition and disclosure boundary before acceptance or publication.
