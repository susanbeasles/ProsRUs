# Product scope and invariants

Job Stack models source observations, claims, profile facts, opportunities, packets, conversations, interviews, reminders and recovery history. Focused domain operations share one closed gateway catalog and current-record guards. Source text never grants pursuit, sending, booking, protection or access.

The production public Worker stays closed; Control is the canonical issuer and selected-grant/session authority. Named private services, signed proofs, current authority and before-acknowledgement checks protect Product/Coordinator access. No new profile selector, grant kind or staged-import route is provided by sanitation.

Audited LOCAL intake is data-only: four required source roles and one optional supplement, strict private profile, original byte hashes/receipts/pointers/order, maximum 256 roles and an 8 MiB complete canonical plan. Legacy v1 reconstruction requires the exact trusted full-plan/time/bundle pin. New profile-v2 identities bind the checked profile digest. Immutable raw evidence remains observational and unversioned until a separately approved recovery operation; no canonical version or intent is fabricated by import.

Optional targeting, discovery windows and literal employment-date extractors are checked settings. Historically absent fields remain absent. Unconfigured fit/rank/discovery return researching/unknown/unavailable; no personal floor or employer is embedded. The strict date family preserves valid existing v1 field bytes.

Recovery retains content-addressed originals, signed metadata, primary saves and honest independent-protection state. The accepted original/audio streaming ceiling is 1 GiB and is separate from the audited JSON plan budget. Providers and automation remain gated; deterministic local outputs do not claim live intelligence or delivery.
